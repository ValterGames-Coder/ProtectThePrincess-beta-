# Remote Config Runtime upgrade guide

- Do not upgrade this package if you are using Unity Editor 2018 LTS or Tech Stream 2019. Versions below 2019.4 (LTS) are not supported.

- There is a new Initialization for Unity Game Services which will require code updates for those who already implemented Remote Config in their Unity Project. Please review the **Initialization** section of [CodeIntegration](CodeIntegration.md) for the new code to be added to your implementation.

- The latest information on the Service features can be found in the [REST API documentation](https://remote-config-api-docs.uca.cloud.unity3d.com/)

For a full list of changes and updates in this version, see the [Remote Config Runtime](../changelog/CHANGELOG.html) package changelog.
